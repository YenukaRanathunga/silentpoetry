# Silent Poetry SL — Fine Art Gallery & Studio

A 3D cinematic fine art portfolio and luxury gallery website designed for artists and collectors.

## Features
- **3D Interactive WebGL Scene**: 1,400+ ambient golden stardust particles and 3D rotating canvas built with Three.js.
- **3D Physics Tilt Cards**: Real-time perspective rotation and dynamic lighting sheen on artwork cards.
- **3D Virtual Exhibition Wall**: Inspect artworks in Studio mode or in a 3D Museum Gallery Wall with spotlighting and plaque details.
- **Ambient Gallery Audio**: Built-in harmonic synthesizer with Web Audio API (toggleable from navigation).
- **Studio Administration**: Integrated artwork catalog manager, pricing, status, and direct login bypass.
- **Acquisition Cart**: Slide-out cart drawer with instant Stripe and PayPal checkout flows.

## Live Deployment
Deployable directly on [Vercel](https://vercel.com).
